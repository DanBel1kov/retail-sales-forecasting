# Прогнозирование продаж: ДЗ 1 и ДЗ 2

Товар: **20725, LUNCH BAG RED RETROSPOT**. В лекции использован 85123A, здесь выбран другой товар.
Цель: прогнозировать количество проданных штук по всем странам, без отмен и возвратов.

## Файлы и порядок работы

1. `01_analysis.ipynb`: ДЗ 1, подготовка данных и исследование ряда.
2. `02_forecasting.ipynb`: ДЗ 2, модели, прогнозы и оценка.
3. `analysis_utils.py`: функции подготовки, диагностики и прогнозирования.
4. `data/processed/`: три готовых ряда и описание источника.
5. `results/`: прогнозы, метрики, проверки качества, разбиения и результаты тестов.
6. `figures/`: все графики в PNG.

Ноутбуки уже выполнены, таблицы и графики сохранены внутри. Запускать сначала ДЗ 1, затем ДЗ 2.
Второй ноутбук также можно выполнить отдельно на сохраненных CSV.

## Запуск

Проверено на Python 3.13. Версии библиотек зафиксированы в `requirements.txt`.
Команды выполняются из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run_all.py
```

На Windows для активации: `.venv\Scripts\activate`.
Для интерактивной работы откройте ноутбуки в Jupyter или VS Code и выберите это окружение.
`run_all.py` последовательно выполняет оба ноутбука и сохраняет результаты.

Исходный Excel лежит в `data/raw/Online Retail.xlsx`. Если его нет, первый ноутбук
скачает архив с UCI и извлечет файл. Для этого нужен интернет. `data/raw/` и `.venv/`
исключены из загрузки через `.gitignore`; подготовленные ряды и результаты остаются в проекте.

## ДЗ 1: данные и выводы

Исходный файл содержит 541 909 строк. У выбранного товара 1639 строк, из них 44 отмены
с отрицательным количеством. После фильтрации остаются 1595 строк.
Пропусков дат и количества у товара нет. 280 строк без CustomerID сохранены:
идентификатор покупателя не нужен для суммарных продаж.

Полные дубликаты сохранены: у позиции нет уникального ID. Совпадающие строки дают
121 штуку, или 0.62% продаж товара. Без подтверждения ошибки их удаление неоднозначно.

Дни без продаж товара отделены от дней без любых транзакций магазина в `results/calendar_audit.csv`.
На основании описания выгрузки как полного журнала ноль означает отсутствие зарегистрированных
продаж. Это не оценка потенциального спроса. Без остатков и журнала сбоев нельзя установить
причину каждого нуля. Среди дней без транзакций есть все субботы и длинный перерыв в конце декабря.

Последний день 09.12.2011 неполный и исключен. Используются:

| Ряд | Период | Наблюдений | Нулей |
|---|---|---:|---:|
| Дневной | 01.12.2010 - 08.12.2011 | 373 | 76 |
| Недельный | недели 06.12.2010 - 04.12.2011 | 52 | 1 |
| Месячный | декабрь 2010 - ноябрь 2011 | 12 | 0 |

Неделя имеет метку воскресенья, месяц имеет метку первого дня. Месячная сумма известна
только после завершения месяца. Неполные крайние недели и месяцы исключены.

- CV: 1.19 для дней, 0.49 для недель, 0.29 для месяцев. Агрегация снижает относительную изменчивость.
- Порог Q3 + 1.5 IQR равен 159 штукам. Отмечено 25 потенциальных выбросов, максимум 432 штуки.
  Они сохранены: большие оптовые заказы входят в задачу прогнозирования.
- STL с периодом 7 выполнена на дневном участке до 24.09.2011 включительно, до всех тестов.
  Средняя трендовая компонента за первые и последние 28 дней выросла с 25.7 до 74.8 штук.
- Сила недельной сезонности 0.184, ACF(7) = 0.154, ACF(14) = 0.192.
  Недельный календарный эффект есть, но нерегулярные продажи дают большую часть колебаний.
  Годовую сезонность по одному году не утверждаем.
- Для исходного дневного ряда ADF p = 2.14e-27, KPSS p = 0.017.
  Результаты противоречивы: единичный корень отвергается, но постоянство уровня тоже.
  После первых разностей ADF p = 3.66e-15, KPSS p >= 0.1.
  Сезонные разности также согласуются со стационарностью, но оба преобразования сразу не нужны.
- Для ДЗ 2 сохранены продажи в исходной шкале. ARIMA рассчитывает разности внутри обучения.
  STL используется только для анализа, ее компоненты не передаются в прогнозные признаки.
- Недельный ряд после первой разности все еще дает противоречивые тесты (KPSS p = 0.042).
  На коротком ряду результат неустойчив; стационарность недельных разностей не утверждаем.

## ДЗ 2: эксперимент

Четыре метода:

- Наивный: повтор последней недели для дней, последнего значения для недель и месяцев.
- Экспоненциальное сглаживание: аддитивная сезонность 7 без тренда для дней; SES для недель и месяцев.
- ARIMA(1, 1, 0) без дрейфа: простой вариант с первыми разностями.
- GradientBoostingRegressor: 80 деревьев, глубина 2, learning_rate 0.05, random_state 42.
  Лаги и скользящие статистики берутся только из прошлого; календарь известен заранее.
  Многошаговый прогноз рекурсивный. Для месяцев после лагов остается всего 6-8 примеров.

Обучение только на прошлом, без перемешивания. В каждом окне строится один прогноз
максимальной длины, короткие горизонты являются его префиксами.
Метрики горизонта h рассчитаны по первым h шагам, а не только по последнему.
Фактические будущие значения в рекурсивные признаки не подставляются.
Отрицательные прогнозы ограничены нулем, дробные значения сохранены.

Основной тест: последние 61 день, 8 недель, 2 месяца. Дополнительно выполнены три окна
с расширением обучения. Их начала сдвинуты на 7 дней, неделю или месяц.
Параметры по тестовым результатам не менялись. Окна перекрываются, это не независимые повторы.
Разбиения доступны в `results/splits.csv`.

Метрики: MAE (основная), RMSE, MASE и sMAPE. MAE и RMSE сравниваются внутри частоты.
MASE масштабируется по обучающим разностям с лагом 7 для дней и 1 для остальных частот.
sMAPE при двух нулях равна 0. MAPE не используется из-за нулевых продаж.
Разные даты тестов и уровни агрегации ограничивают сравнение частот даже по безразмерным метрикам.

## Лучшие модели на основном тесте

| Частота   |   Горизонт | Модель                       |    MAE |   RMSE |   MASE |
|:----------|-----------:|:-----------------------------|-------:|-------:|-------:|
| День      |          1 | Наивная                      |   2.00 |   2.00 |   0.04 |
| День      |          7 | Наивная                      |  29.29 |  46.33 |   0.57 |
| День      |         31 | Наивная                      |  33.39 |  46.23 |   0.65 |
| День      |         61 | Эксп. сглаживание            |  31.02 |  41.76 |   0.60 |
| Месяц     |          1 | Наивная                      | 448.00 | 448.00 |   0.84 |
| Месяц     |          2 | Наивная / эксп. сглаживание* | 314.00 | 341.40 |   0.59 |
| Неделя    |          1 | Эксп. сглаживание            |  43.23 |  43.23 |   0.21 |
| Неделя    |          4 | Наивная                      |  44.00 |  64.85 |   0.22 |
| Неделя    |          8 | Бустинг                      |  98.25 | 142.39 |   0.49 |

\* На двух месяцах наивный метод и сглаживание имеют одинаковую MAE = 314.
В строке показаны RMSE и MASE наивного метода. Полные метрики обоих методов есть в `metrics_final.csv`.

На дневных горизонтах 1, 7 и 31 лучше наивный прогноз, на 61 дне лучше сглаживание.
На первом тестовом дне фактически продано 2 штуки, наивный прогноз равен 0:
MAE = 2, но sMAPE = 200%. Около нуля процентная ошибка может быть высокой при малой абсолютной ошибке.

Для недель победитель зависит от горизонта. На восьми неделях MAE бустинга 98.25,
наивного метода 99.13, ARIMA 99.51. Разница мала и не подтверждает устойчивое преимущество бустинга.
Для месяцев один шаг лучше прогнозирует наивный метод, на двух шагах у него равная MAE со сглаживанием.

При усреднении трех окон победители меняются в 7 из 9 случаев (`rolling_winners.csv`).
Сглаживание остается лучшим на 61 дне и одной неделе. На недельных горизонтах 4 и 8
по среднему трех окон лучше ARIMA. Месячный победитель меняется на сглаживание для одного шага
и бустинг для двух шагов. Это показывает чувствительность результата к дате прогноза.

Ошибка не обязана монотонно расти с горизонтом: MAE усредняется по разным наборам будущих точек.
Монотонный рост наблюдается только у недельного сглаживания. У всех месячных моделей
ошибка двух месяцев ниже ошибки первого месяца, потому что второй месяц предсказан точнее.

Главные ограничения: один год истории, 12 месяцев, редкие крупные заказы, отсутствие остатков
и информации об акциях. Нужна более длинная история и новый период проверки для окончательного
выбора модели. Победители здесь описывают текущий эксперимент, а не гарантируют будущий результат.
